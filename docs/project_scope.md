# Project scope

This MVP demonstrates a repeatable local analytics workflow:
1. Raw observations are read from CSV.
2. Required fields and numeric values are validated.
3. Clean observations are written to the Silver layer.
4. City, daily, monthly and pollutant aggregates are written to the Gold layer.
5. A local interactive dashboard presents filtered analytics.

It is an educational demonstration, not a pollution-monitoring service or public-health tool.
